## TASK #2 › Bell Numbers

Submitted by: Mohammad S Anwar

Write a script to display top 10 Bell Numbers. Please refer to wikipedia page for more informations.

### Uiua

```
# Triangle (addition) scheme to produce terms, 
# derived from the recurrence, 
# from Oscar Arevalo (loarevalo(AT)sbcglobal.net), 
# May 11 2005:
#     1
#     1  2
#     2  3  5
#     5  7 10 15
#    15 20 27 37 52
#    ... [This is Aitken's array A011971]

BellNumber ← (
  ⊣˜⍥(⊙◌⍢(⊂⟜(+⊙°⊂⊣)|≠0⋅⧻)[∘]⊸⊣)[1]
)

≡(BellNumber) ⇡ 10
```
